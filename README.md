# CYMA WordPress

WordPress theme converted from Webflow for CYMA Systems. Runs locally with Docker.

## Quick start

```bash
git clone https://github.com/adeemad/cyma-wordpress.git
cd cyma-wordpress
docker compose up -d
```

Open **http://localhost:8081**
